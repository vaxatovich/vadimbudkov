# Вадим Будьков — персональное портфолио

Статический сайт на русском языке: главная, «Обо мне», примеры публикаций и карьерная хронология, страница «Кейсы» (пока заглушка).

## Структура

- `index.html` — главная
- `about.html` — опыт, публикации, результаты и скриншоты статистики
- `cases.html` — заглушка «Страница в разработке», с `noindex`
- `styles.css`, `assets/` — оформление и иллюстрации
- `robots.txt` — отдельный `Allow: /` для Googlebot, Bingbot, OAI-SearchBot и остальных
- `sitemap.xml` — две готовые индексируемые страницы
- `llms.txt` — необязательный справочный файл
- `SEO_SETUP.md` — **инструкция для Google Search Console и переезда на Vercel**

## Production URL

**Основной адрес сайта:** https://vadimbudkov.vercel.app/

Vercel автоматически развертывает обновления из ветки `main`.

Canonical, sitemap и robots настроены для Vercel. Перед добавлением в Search Console проверьте индексацию URL через инспектор Google.

### Важно для GitHub Pages

GitHub Pages проектного репозитория обслуживает `robots.txt` по пути `/vadimbudkov/robots.txt`, но поисковые роботы обычно запрашивают **`/robots.txt` на корне хоста**. Такой файл под проектным префиксом не считается host-level robots.txt. На Vercel или собственном домене этот же файл окажется в корне хоста и сможет управлять обходом.

Файлы с кодом поддерживаются в ветке `main`. Названия профессий — по-русски; в видимом тексте название платформы пишется «телеграм».
