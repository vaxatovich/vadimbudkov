# Вадим Будьков — сайт-портфолио

Две статические страницы (главная и «Обо мне») в стиле детского рисунка.

Сайт: https://vaxatovich.github.io/vadimbudkov/

## Файлы
- `index.html` — главная
- `about.html` — опыт, публикации, карьерная хронология
- `styles.css` — стили и адаптивная верстка
- `assets/` — оригинальные иллюстрации
- `robots.txt`, `sitemap.xml` — индексирование

## Публикация
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root).

Все ссылки относительные к текущей папке, поэтому сайт работает как GitHub Pages project-site в `/vadimbudkov/`.

После публикации сайт можно добавить в Google Search Console и Яндекс Вебмастер.

Пока раздел «Кейсы» ведет на «Примеры контента»; отдельная страница кейсов еще не создана.
